# Sécurité Oracle Database 19c — Travaux Pratiques

**Étudiante :** Manar Ouberri — Filière Cybersécurité
**Environnement :** Oracle Database 19c EE (19.3), Oracle Linux — CDB `SECBANK`, PDB `SECBANKPDB`

Ce dépôt regroupe les rapports et scripts SQL des TP du module *Administration & Sécurité Oracle Database 19c* (projet SecureBank).

| Dossier | TP | Thèmes |
|---|---|---|
| [`TP2-SecureBank`](TP2-SecureBank) | Séance 2 — Gestion des accès bancaires et chiffrement | Rôles, profils, TDE, chiffrement de colonne, VPD, audit unifié, investigation |
| [`TP3-Durcissement-Monitoring`](TP3-Durcissement-Monitoring) | Séance 3 — Durcissement, monitoring et réponse aux incidents | Durcissement, chiffrement réseau, injection SQL, détection automatique, RMAN chiffré, incident |

Chaque dossier contient :

- le **rapport** (`.docx`) ;
- un **README** (contenu, ordre d'exécution, corrections apportées à l'énoncé) ;
- les **scripts** SQL / shell / RMAN corrigés et commentés.

> Les mots de passe présents dans les scripts sont des valeurs de TP, à ne jamais réutiliser en production.
